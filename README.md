# Telco Customer Churn Prediction

End-to-end Machine Learning project for predicting customer churn using customer demographic and service usage data.

## Features
- Exploratory Data Analysis (EDA)
- Feature Engineering
- SMOTE for class imbalance handling
- Scikit-learn Pipelines
- XGBoost Classifier
- Streamlit Deployment

## Technologies Used
- Python
- Pandas
- Scikit-learn
- XGBoost
- Streamlit

## Files
- `app.py` → Streamlit application
- `pipeline_xgb.pkl` → Trained ML pipeline
- `requirements.txt` → Dependencies
- `Telco-Customer-Churn.ipynb` → Model development notebook

## Deployment
Deployed using Streamlit Community Cloud.
